# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 多窗口协作（无需服务器）

在同一台电脑上开多个浏览器窗口（同一浏览器、同一地址）即可共同编辑一份插画。窗口之间通过
`BroadcastChannel` 直接通信，没有服务端，也不依赖账号。

- **各窗口本地独立**：选区、缩放、当前工具只属于本窗口，不会同步。
- **文档同步**：节点移动、分组、排序与样式修改都以“按对象”的小增量广播（每次最多一条路径的
  锚点或一个样式字段），不会在每次移动时传整份文档。
- **并发合并**：每个样式字段、每个锚点各是一个带 Lamport 时钟的“后写者胜”寄存器。两人改不同
  属性或不同锚点时二者都保留；改同一处时按（时钟, 窗口 id）确定性收敛，两边显示完全一致。
- **删除优先**：删除以墓碑记录，任何针对已删除对象的迟到写入都会被拒绝，因此“一人移动、另一人
  删除”最终一定是删除，并会提示“已被另一窗口删除，本次修改未应用”。
- **撤销/重做**：每个窗口只记录自己的操作。撤销前会核对该记录仍持有本窗口写入的值；若他人已改，
  则保留他人结果并提示。撤销创建时，仅当该图层的所有写入都来自本窗口时才会整层移除。
- **后台窗口追赶**：窗口加入、恢复可见或重新连接时，向同伴请求一份压缩后的状态快照，而不是重放
  全部历史。操作日志不入库；持久化前会压缩掉已删除图层的字段与锚点。
- **切换/恢复文档**：`Restore` 会开启新的文档代号（generation），旧代号的迟到消息在频道层就被
  丢弃，不会串入新文档，其他窗口会同步切换到同一版本。
- **导出**：只读取一份明确提交的版本（每次应用批次后生成），拖动过程中的预览不会混入。导出按钮
  显示版本号，界面同时显示“正在同步 / 已同步 · N 个协作窗口”。

数据保存在本机 `localStorage`，旧版 `forma-document` 数据会在首次启动时自动迁移。
